# QWEN.md — policy-search-frontend

Next.js (App Router) + Tailwind + TypeScript frontend for the youth /
small-business policy search platform. Korean-first (`lang="ko"`, Pretendard).
Dev server: port 3001. Contracts (types incl. `MatchStatus`) live in
`@policy-search/contracts` from the sibling backend.

## Design System (oh-my-design)

**Before any UI, styling, copy, or motion change, open and read `./DESIGN.md`
in full.** It is the standalone design contract (KRDS-referenced, tri-state
eligibility semantics). If `.omd/preferences.md` exists, pending explicit
corrections there override the contract until folded in. The omd-* skills
(omd-apply, omd-designer-review, omd-slop-audit, omd-feel, omd-final-qa) are
installed globally and may be invoked for UI work.
